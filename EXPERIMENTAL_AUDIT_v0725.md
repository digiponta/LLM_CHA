# v0.7.25 — Experimental Sleep Audit

Adds a read-only GPU evaluation comparing responses generated by the
frozen **Base model** and the **post-/sleep Experimental Adapter**, using
the same questions. No new learning or promotion is performed.

Reports:
- Exact-match on current PENDING Candidate training questions.
- Exact-match on optional separately supplied, ID-matched paraphrases.
- Exact-match on any current Approved records (diagnostic only).
- SHA-256 of Base model, tokenizer, Approved/Candidate JSONL, Experimental
  checkpoint and optional holdouts, **before and after the evaluation**.

**Interpretation:** This is a Base vs trained-Experimental comparison, NOT
a genuine pre-/sleep vs post-/sleep adapter longitudinal experiment unless
you separately save and evaluate the earlier Experimental checkpoint.
The program does not claim to measure forgetting from earlier versions;
a valid forgetting study requires successive snapshots and a fixed probe set.
If no Approved entries exist, Approved retention is unmeasured. Hash
equality covers the audit execution window, not a prior /sleep event.

## PowerShell
```powershell
git fetch origin
git switch --track origin/v0.7.25
python -m unittest -v test_experimental_audit_v0725.py test_experimental_restore_v0724.py
python audit_experimental_sleep_v0725.py --adapter results/experimental_sleep_v0722/experimental-sleep-88c3cbc845c6ff0d0973.pt
```

Report: `results/experimental_audit_v0725/report.json`.

To use independent paraphrases, provide `--holdouts your_file.json` with
a JSON array of `question`, `reference`, and `candidate_id` entries.
Every referenced Candidate must currently be PENDING and its answer must
match. Training questions are rejected as holdouts.

No Trusted checkpoint changes, no Candidate status changes, and no
automatic promotion. Only this benchmarking utility and its tests are
added; production `chat.py` remains untouched.
