# v0.13.58.83.00 — Retrieval–Selection–Expansion (RSE), Phase 1

Goal: select a stored reply to a relevant user question, then later investigate context-aware expansion. This initial implementation does **not** generate, train or edit chat.py. Retrieval is based only on source question text, not the response itself. The score is simple exact token overlap with IDF weighting; a score of 1.0 does **not** establish semantic or conversational correctness. Selected replies are labeled SELECTED_REVIEW_REQUIRED rather than ready for automatic user presentation. The data may contain personal experiences: do not imitate source speaker CP.


Default output and saved report omit dialogue text; `--show-answers` prints candidate replies locally for review. Avoid publishing raw copyrighted conversation transcripts. Because Japanese word-level tokenization here uses simple character runs rather than Sudachi, partial matches and zero matches are common; this is an intentionally modest baseline for evaluation. Future phases: morphology-aware BM25/embedding retrieval; separately score question–answer relevance and speaker claims; use dialogue-grouped held-out evaluation; expansion only after selection is verified.

The existing model checkpoint `model/real-persona-cp-pilot-v013588296.pt` stays unmodified; Semantic Memory routes stay untouched.
