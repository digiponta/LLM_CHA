# LLM_CHA v0.13.58.82.69 — Sense Candidate Review / Staging

The five v0.68 discovery records can be reviewed individually. No candidate is automatically approved. Reviewer identity and a written justification are required to record APPROVE, REJECT, or DEFER. Duplicate/conflict candidates cannot be approved without additional resolution. Stale meaning/evidence in a review entry are excluded from staging. The report generated by this module is a **separate staged semantic record set**, not a write to the production Semantic Memory or proposition stores. Approval here means **human review recorded**, not external factual truth verification and not a model update.

Windows PowerShell:

    cd C:\Users\inoma\git\misc\LLM_CHA
    git fetch origin
    git switch v0.13.58.82.69-sense-review-stage
    python -m unittest -v test_sense_review_v013588269.py test_sense_discovery_v013588268.py test_generalized_sense_v013588267.py
